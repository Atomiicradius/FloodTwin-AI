# Sources

Every assumed parameter range or method gets an entry here (referenced from `configs/params/ranges.yaml` via `source_note`). Do not add a citation you have not actually read.

| Topic | Source (author, year, title/URL) | What it supports | Added by |
|---|---|---|---|
| Manning's n for closed conduits and lined channels | Chow, V.T. (1959), *Open-Channel Hydraulics*; tables reproduced in EPA SWMM Reference Manual Vol. 2 (Hydraulics), Tables G-1 and G-2, <https://downloads.tuflow.com/SWMM/SWMM5_Reference_Manual_Volume2_Hydaulics_P100S9AS.pdf> | Concrete sewer with manholes n = 0.013–0.017; cemented rubble masonry n = 0.018–0.030. Basis for the 0.013–0.035 `conduit_manning_n` range. | Role B |
| SWMM model concepts, infiltration methods and continuity reporting | US EPA (2022), *Storm Water Management Model User's Manual, Version 5.2*, EPA/600/R-22/030, <https://www.epa.gov/system/files/documents/2022-04/swmm-users-manual-version-5.2.pdf> | Horton / Green-Ampt / Curve Number definitions; subcatchment parameter meanings; runoff and flow-routing continuity reporting used in the toy run note. | Role B |
| Green-Ampt infiltration parameters | Rawls, W.J., Brakensiek, D.L. & Miller, N. (1983), "Green-Ampt infiltration parameters from soils data", *J. Hydraul. Eng.* 109(1), 62–71; tabulated values read from the TUFLOW wiki reproduction, Table 1, <https://wiki.tuflow.com/Green-Ampt_Infiltration_Parameters> | Capillary suction 49.5–316.3 mm; saturated conductivity 0.3–117.8 mm/hr; porosity 0.31–0.49 across USDA textures. Basis for the infiltration ranges. | Role B |
| Imperviousness by land use | Mile High Flood District (2024), *Urban Storm Drainage Criteria Manual, Volume 1*, Chapter 6 Runoff, Table 6-2, <https://www.mhfd.org/files/11d6efc42/06_Runoff+March+2024.pdf> | Recommended imperviousness: residential 0.35–0.70, commercial 0.65–0.90, industrial 0.75. Basis for the 0.40–0.95 `imperviousness` range. | Role B |
| PySWMM toolchain | McDonnell, B.E. et al. (2020), "PySWMM: The Python Interface to Stormwater Management Model (SWMM)", *JOSS* 5(52):2292, <https://doi.org/10.21105/joss.02292>; project documentation <https://www.pyswmm.org> | Python wrapper around the SWMM 5 engine used for the Phase 1 toy verification (`pyswmm` 2.2.0). | Role B |
